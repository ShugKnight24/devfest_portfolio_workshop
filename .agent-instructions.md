## Operational Directives

1. **Accessibility (a11y)**:
   - Hit WCAG AA standards.
   - Always enforce `:focus-visible` outlines (2px solid neon primary with offset).
   - Use semantic tags: `<nav>`, `<header>`, `<main>`, `<article>`, `<section>`, `<footer>`.
   - Never use raw emojis in UI; use `@portfolio/icons` SVGs.

2. **Zero Bloat & Web Sovereignty**:
   - Modern CSS, Flexbox/Grid, and native Web APIs (LocalStorage, Web Audio, Clipboard).
   - No unnecessary dependencies.

3. **Fluid Typography**:
   - Use CSS `clamp()` for responsive text scaling across 320px to 4K displays.

4. **Error Resilience**:
   - All dynamic components and pages must be protected by `<ErrorBoundary>` to avoid white screens.
   - Fallback UI must state: `"SYSTEM OFFLINE: CHECK YOUR CODE"` with 1-click Reacher prompt copy.

5. **Token Discipline**:
   - Write terse, high-signal explanations (Caveman / Cove active).
   - Output exact file diffs.
