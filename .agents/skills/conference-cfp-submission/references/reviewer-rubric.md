# Reviewer rubric and pre-submit checklist

Score the pack as a reviewer would: cold, fast, next to dozens of rivals, with no knowledge of the speaker beyond the form.

## Scoring anchors

### Content - is it coherent, structured and deliverable?

| Score | Anchor                                                                               |
| ----- | ------------------------------------------------------------------------------------ |
| 1     | A topic, not a talk. No structure, no evidence the material exists                   |
| 2     | A structure implied but not shown; scope larger than the slot                        |
| 3     | Clear shape, outline present, but generic sections ("background", "lessons learned") |
| 4     | Outline with minutes, each section carrying one point, scope matched to the slot     |
| 5     | The above, plus the hardest part of the talk is visibly already solved               |

### Originality - is the idea, angle or data new?

| Score | Anchor                                                             |
| ----- | ------------------------------------------------------------------ |
| 1     | A version of this ran at this event recently, unchanged            |
| 2     | Common topic, common angle, no data of the speaker's own           |
| 3     | Common topic with a specific context that has not been shown here  |
| 4     | A lens the programme lacks: new data, a failure, a contrarian read |
| 5     | Something only this speaker could submit                           |

### Relevance - right event, right track, right moment?

| Score | Anchor                                                                 |
| ----- | ---------------------------------------------------------------------- |
| 1     | Wrong audience entirely, or a sales pitch                              |
| 2     | Adjacent to the event's subject; track chosen by name, not description |
| 3     | Fits the track, timing neutral                                         |
| 4     | Matches the track description's own wording and the level of the room  |
| 5     | Answers a question this community is actively arguing about            |

### Speaker - right person, evidenced?

| Score | Anchor                                                                  |
| ----- | ----------------------------------------------------------------------- |
| 1     | Enthusiasm and seniority claims only                                    |
| 2     | Relevant job title, nothing tying the speaker to this specific material |
| 3     | Clear first-hand involvement, no external evidence                      |
| 4     | First-hand involvement plus checkable artefacts (repo, post, data)      |
| 5     | The above plus a recording of a previous talk                           |

A proposal scoring 3 across the board is a proposal that will be beaten. Push Content and Originality to 4 before submitting. That priority is this skill's own call, not a published weighting - no committee publishes per-axis weights - but it is where the documented rejection patterns cluster: undeliverable scope and no angle on a well-worn topic.

## Pre-submit checklist

Copy: rules

- [ ] Title within cap, specific, no unexplained pun, no question mark, no product name at a vendor-neutral event
- [ ] Abstract within cap, complete sentences, opens on the problem
- [ ] Voice matches the house style visible on last year's schedule
- [ ] At least one number, system or scale the speaker can source
- [ ] Takeaways verb-first, scoped to the slot
- [ ] No claim the speaker cannot defend from a stage

Fields

- [ ] Reviewer-only text says something the abstract does not
- [ ] Outline has minute estimates and two levels
- [ ] Track matches the track description
- [ ] Audience level honest
- [ ] Prerequisites stated for a workshop
- [ ] Supplemental links open and are public

Rules

- [ ] Inside the per-person submission cap for this event
- [ ] Content not previously delivered where the event forbids it
- [ ] Panel or co-speaker composition rules satisfied, everyone confirmed
- [ ] Event's AI policy read, and the copy rewritten in the speaker's own voice
- [ ] Anonymity respected if the first round is blind
- [ ] Affiliation disclosed where the form asks
- [ ] Speaker terms acceptable: travel, ticket, recording licence, employer approval

Logistics

- [ ] Deadline and notification date recorded, with the event date checked against the calendar
- [ ] Proposal saved outside the submission platform for reuse
- [ ] Submitted early enough to qualify for mentorship or feedback where the event offers it

## Reviewing someone else's draft

When the user brings an existing proposal instead of an idea, run the rubric first and report scores with reasons before rewriting anything. A rewrite that arrives before the diagnosis teaches the user nothing, and they will need the diagnosis for the next CFP - the proposal is one submission, the pattern is a season.
